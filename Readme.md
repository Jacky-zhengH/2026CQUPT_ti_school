## <a id="1-项目软件系统架构综述"></a>1. 项目软件系统架构综述

本小节将概述系统如何通过分层架构（BSP驱动层、Algo算法层、App业务层）实现模块化设计，以及在 STM32F407 平台上如何平衡实时采样与 UI 交互。

## <a id="2-底层通信技术详析：串行外设接口 (SPI)"></a>2. 底层通信技术详析：串行外设接口 (SPI)

详细展开本项目涉及的两种 SPI 实现形式：
- **软件模拟 SPI (Bit-banging)**：在 AD7606 串行读取中的应用，重点分析 Setup/Hold Time（建立保持时间）与 NOP 指令在纳秒级延时中的作用。
- **SPI 通信协议要素**：
    - 四种时钟极性（CPOL）与相位（CPHA）模式的对比。
    - MSB/LSB 传输顺序对 16 位 ADC 数据拼接的影响。
    - 主从模式下的信号完整性与上拉电阻的作用。

## <a id="3-控制核心逻辑：非阻塞状态机 (FSM) 的构建与优势"></a>3. 控制核心逻辑：非阻塞状态机 (FSM) 的构建与优势

分析本项目中用于测量 $R_{out}$ 的状态机设计：
- **代码编写模式**：基于 `switch-case` 结合 `HAL_GetTick()` 的非阻塞结构。
- **为什么不用阻塞延时**：对比 `HAL_Delay()` 与状态机轮询在 HMI 响应速度和继电器机械保护上的差异。
- **状态迁移图逻辑**：从测量空载、切换继电器、等待稳定到带载采样的全流程控制。

## <a id="4-进阶信号处理：快速傅里叶变换 (FFT) 深度解析"></a>4. 进阶信号处理：快速傅里叶变换 (FFT) 深度解析

探讨若从 RMS 方案切换回“交流直采”方案时，软件算法的巨大变化：
- **数学基础**：离散傅里叶变换 (DFT) 的对称性与基-2 蝶形运算的加速原理。
- **软件实现**：调用 CMSIS-DSP 库的实战技巧（位反转、旋转因子缓存）。
- **核心算法应用**：
    - **幅值提取**：通过 $\sqrt{Re^2 + Im^2}$ 计算 10kHz 频点的有效值。
    - **相位测量**：计算输入输出序列在复平面上的向量夹角。
    - **频谱泄露与加窗**：为什么在非整数周期采样下必须引入 Hanning 窗或 Hamming 窗。

## <a id="5-工程问题归纳与排查手册 (Troubleshooting)"></a>5. 工程问题归纳与排查手册 (Troubleshooting)

汇总开发过程中遇到的典型问题：
- **输入电阻测量死区**：由于高阻环境导致的 $V_1, V_2$ 极小压差提取，以及软件滤波与硬件改阻的博弈。
- **串口通信异常**：ORE (Overrun Error) 导致 DMA 锁死的机制与软件清除恢复方案。
- **噪声抑制**：使用滑动平滑滤波算法`moving average`
